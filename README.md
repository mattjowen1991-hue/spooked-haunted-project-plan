# Spooked Haunted Project

- `index.html` is the SHP CapCut Guide: a step-by-step way to edit a three-camera investigation in CapCut desktop, using free features.
- `log/` is the SHP Log, a phone app for marking moments during an investigation. It works offline once opened and sends the log to WhatsApp. The Combine tab merges everyone's logs into one timeline for editing.
- `king-charles-house/` is the run sheet from the King Charles House investigation, October 2026.

Served with GitHub Pages from the `main` branch. Put together by Matt.

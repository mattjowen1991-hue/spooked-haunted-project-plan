# Spooked Haunted Project Edit Plan

A one-page, phone-friendly plan for how each Spooked Haunted Project investigation becomes a tight main episode, a set of shorts and the odd live vigil.

- `index.html` is the plan page
- `king-charles-house/` is the run sheet for the King Charles House investigation, Sunday 11 October 2026: timeline, opening and history scripts, room by room cards, vigil method, question bank and wind down. Copy the folder for each new location.
- `log/` is the SHP Log, a phone app for marking moments during an investigation. It saves on the phone, works offline once opened, and sends the log to WhatsApp. The Combine tab merges everyone's logs into one timeline for editing.

Served with GitHub Pages from the `main` branch.

Put together by Matt, October 2026.
